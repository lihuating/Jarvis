# OSS 命令行工具使用规则

## 规则简介

OSS Utils CLI 是一个统一的命令行工具，用于处理 RDC、iCenter 和 UAC 相关操作。本规则定义了 oss 命令的使用规范、最佳实践和注意事项。

## 你必须遵守的原则

### 1. 命令结构原则

**要求说明：**

- **必须**：使用标准的命令结构 `oss [OPTIONS] COMMAND [ARGS]...`
- **必须**：在使用子命令前先了解其功能和参数
- **禁止**：未经测试直接在生产环境使用复杂操作

**示例：**

```bash
# 查看主命令帮助
oss --help

# 查看子命令帮助
oss rdc --help
oss icenter --help
oss uac --help
```

### 2. RDC 工作项查询原则

**要求说明：**

- **必须**：使用 `oss rdc search` 查询 RDC 工作项时提供有效的查询参数
- **必须**：了解查询结果的字段含义
- **禁止**：使用模糊查询导致返回过多无关结果

### 3. iCenter 页面管理原则

**要求说明：**

- **必须**：在创建/更新 iCenter 页面前先使用 `get` 或 `subtree` 命令获取当前状态
- **必须**：确认页面 ID 或路径的准确性，避免误操作
- **禁止**：在没有备份或确认的情况下直接更新重要页面

### 4. UAC 认证操作原则

**要求说明：**

- **必须**：在执行认证操作前确保环境配置正确
- **必须**：妥善保管认证相关的配置信息
- **禁止**：在不安全的环境中执行认证操作或暴露认证信息

## 你必须执行的操作

### 操作1：使用 oss 命令查询 RDC 工作项

**执行步骤：**

1. 使用 `oss rdc --help` 了解可用的子命令
2. 使用 `oss rdc search --help` 了解查询参数
3. 执行具体的查询操作
4. 验证查询结果的准确性

### 操作2：使用 oss 命令管理 iCenter 页面

**执行步骤：**

1. 使用 `oss icenter --help` 了解可用的子命令
2. 使用 `oss icenter get [PAGE_ID]` 获取当前页面内容（如适用）
3. 执行创建/更新操作
4. 验证操作结果

### 操作3：使用 oss 命令测试 UAC 认证

**执行步骤：**

1. 使用 `oss uac --help` 了解可用的子命令
2. 使用 `oss uac auth` 测试认证功能
3. 验证认证结果

## 检查清单

在使用 oss 命令时，你必须确认：

- [ ] 已通过 `oss --help` 了解主命令结构和选项
- [ ] 已了解所需子命令的功能和参数（`oss rdc --help`, `oss icenter --help`, `oss uac --help`）
- [ ] 已确认当前环境可以正常访问 RDC、iCenter 和 UAC 服务
- [ ] 对于修改操作，已做好备份或确认可以安全执行
- [ ] 遵循了与认证和安全相关的最佳实践
