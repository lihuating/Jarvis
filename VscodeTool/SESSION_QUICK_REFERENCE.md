# 会话功能 - 快速参考

## 🎯 核心功能

| 功能 | 说明 | 状态 |
|------|------|------|
| 多轮对话 | 第一个问题和第二个问题有关联 | ✅ 支持 |
| 会话保持 | 自动保存和恢复会话 | ✅ 支持 |
| 会话名称显示 | 界面顶部蓝色徽章显示 | ✅ 支持 |
| New Chat | 一键重置会话 | ✅ 支持 |
| 会话模式切换 | persistent / single-use | ✅ 支持 |

---

## 🚀 快速开始

### 默认使用（推荐）

无需任何配置，直接开始使用！

```
1. 打开 VSCode 插件（Ctrl+Shift+P → Jarvis: Open Chat）
2. 输入第一个问题
3. 看到界面顶部显示会话名称（蓝色徽章）
4. 输入第二个问题，AI 会理解上下文
5. 需要新话题时，点击 "New Chat" 按钮
```

## ⚙️ 配置选项

### 会话模式配置

```json
{
  "jarvis.sessionMode": "persistent"  // 默认：持久会话
}
```

**可选值**：
- `"persistent"` - 持久会话模式（保持上下文）
- `"single-use"` - 单次会话模式（每次独立）

### 如何修改配置

**方法 1：设置界面**
```
1. Ctrl+, 打开设置
2. 搜索 "jarvis.sessionMode"
3. 选择 "persistent" 或 "single-use"
```

**方法 2：settings.json**
```
1. Ctrl+Shift+P
2. 输入 "Preferences: Open Settings (JSON)"
3. 添加配置项
```

## 📁 会话文件

### 位置
```
~/.jarvis/sessions/
├── vscode-1715424000000_saved_session_jca_*.json
├── vscode-1715424100000_saved_session_jca_*.json
└── ...
```

### 内容示例
```json
{
  "session_name": "vscode-1715424000000",
  "messages": [
    {"role": "user", "content": "分析这段代码..."},
    {"role": "assistant", "content": "这段代码实现了..."},
    {"role": "user", "content": "如何优化？"},
    {"role": "assistant", "content": "可以从以下几个方面..."}
  ]
}
```

### 清理旧会话

```bash
# 查看会话文件
ls -lh ~/.jarvis/sessions/

# 删除旧会话
rm ~/.jarvis/sessions/vscode-*.json

# 或者保留最近 10 个
cd ~/.jarvis/sessions/
ls -t vscode-*.json | tail -n +11 | xargs rm
```

## 🔧 故障排查

### 问题 1：会话不保持上下文

**检查**：
```
1. 确认配置是 "persistent" 模式
2. 查看界面顶部是否有会话名称显示
3. 检查后端命令是否包含 --session-name 参数
```

**解决**：
```
1. 点击 "New Chat" 按钮
2. 重新发送问题
3. 如果还不行，重启 VSCode
```

### 问题 2：会话名称不显示

**检查**：
```
1. 查看是否点击了 "New Chat" 按钮
2. 检查是否是 "single-use" 模式
```

**解决**：
```
1. 发送一个新问题
2. 会话名称会自动显示
```

### 问题 3：会话文件过多

**解决**：
```bash
# 定期清理旧会话
cd ~/.jarvis/sessions/
ls -t vscode-*.json | tail -n +11 | xargs rm
```

## 🎯 最佳实践

### ✅ DO（推荐）

- ✅ 使用持久会话模式进行代码开发
- ✅ 完成大任务后点击 "New Chat"
- ✅ 切换项目时点击 "New Chat"
- ✅ 定期清理旧会话文件
- ✅ 在复杂任务中使用上下文

### ❌ DON'T（避免）

- ❌ 在单次模式下期望上下文保持
- ❌ 不清理旧会话文件（占用空间）
- ❌ 在不同项目间混用同一个会话
- ❌ 在会话中混合多个不相关的任务
