# 9200基站操作规则

## 规则简介

本规则定义了 9200 基站的标准操作流程，包括 SSH 登录、基带板操作、文件传输、日志收集等。在需要对 9200 基站进行任何操作时，必须遵守本规则。

## 触发条件

- 用户要求操作 9200 基站（登录、文件传输、日志采集等）
- 用户提到基站 IP 地址（192.254.x.16 格式）
- 用户要求分析基站日志或黑匣子
- 用户要求查看基站系统信息

## 你必须遵守的原则

### 1. SSH 登录规范

**要求说明：**

- **必须**：按以下凭据登录主控单板
  - 用户名：`itran`，密码：`Itran_2430!@#`
  - 命令：`ssh itran@<主控单板IP>`
- **必须**：基带板需通过主控板中转登录
  - 用户名：`root`，密码：`Itran_2430!@#$`
  - 步骤：先 SSH 登录主控板，再从主控板 SSH 登录基带板
- **禁止**：直接从外部 SSH 登录基带板（基带板不支持外部直接登录）

### 2. IP 地址规则

**要求说明：**

- **必须**：按以下规则确定单板 IP
  - 主控单板：1 槽位 `192.254.1.16`，2 槽位 `192.254.2.16`
  - 基带板：`192.254.槽位号.16`（如 3 槽位 `192.254.3.16`）
- **禁止**：猜测或随意使用 IP 地址，必须确认槽位号后再计算 IP

### 3. 基带板文件回传流程

**要求说明：**

- **必须**：按以下步骤执行文件回传（假设主控板 1 槽位，基带板 3 槽位）：
  1. SSH 登录主控板：`ssh itran@192.254.1.16`
  2. 从主控板 SSH 登录基带板：`ssh root@192.254.3.16`
  3. 在基带板上 SFTP 登录主控板：`sftp itran@192.254.1.16`
  4. 使用 `put` 命令传输文件到 `/home/itran/`
- **必须**：SFTP 目标地址根据主控板实际槽位选择
  - 主控板 1 槽位：`sftp itran@192.254.1.16`
  - 主控板 2 槽位：`sftp itran@192.254.2.16`
- **禁止**：在不确定槽位的情况下执行文件传输

### 4. 重要路径

**要求说明：**

- 主控单板蓝图位置：`/mnt/flash/nfc/1/run`
- 主控板用户目录：`/home/itran/`
- 基带板用户目录：`/root/`
- 主控板日志目录：`/logs/OssLog/` 或 `/logs/oss/oss/容器名/`
- 基带板日志目录：`/mnt/flash/OssLog/` 或 `/mnt/flash/BBX/`

### 5. 日志采集规范

**要求说明：**

- **必须**：采集日志前确认目标单板类型和日志路径
- **必须**：采集的日志文件按类型分类保存
- **禁止**：在工程目录下随意保存采集文件

**日志类型与关键文件：**

| 故障类型 | 关键日志文件 |
|---------|------------|
| 单板复位 | BBX_Simplelog.cur、黑匣子 .bbx.gz、Kernel-XX.log.gz |
| 容器复位 | exit.txt-0X.gz、黑匣子 .bbx.gz、coredump 文件 |
| CPU 冲高 | OssCoreCpu.log、OssCpu.log、OssCpuLoop.log |
| 内存问题 | ProcMemInfo.log、MemLeak_XXXXXX.log、oomMoni_XXXXXX.log |
| 初始化 | mgr_init.log、cpplink_info |
| 通信问题 | HwmpackageInfo.log、ipmimsg.log、bootp.log |

### 6. 故障定位工作规范

**要求说明：**

- **必须**：在当前工作目录下创建 `bug_xx`（xx 是数字）专用目录存放中间文件
- **必须**：所有采集信息、中间文件、分析结果都放在该目录下
- **必须**：每次分析新问题创建新的 bug_xx 目录，编号按顺序递增
- **禁止**：在工程其他目录下创建或保存中间文件

### 7. 常用检查命令

**系统信息：**
```bash
uname -a              # 系统信息
cat /proc/cpuinfo     # CPU 信息
cat /proc/meminfo     # 内存信息
df -h                 # 磁盘使用
```

**进程信息：**
```bash
ps -ef                # 所有进程
ps -ef | grep <进程名>  # 特定进程
pstree                # 进程树
```

**网络相关：**
```bash
ifconfig              # 网络接口
route -n              # 路由表
ping <目标IP>         # 连通性测试
```

**内存采集：**
```bash
cat /proc/mm/processinfo    # 进程内存
cat /proc/mm/kernelinfo     # 内核内存
cat /proc/mm/fileinfo       # 文件内存
```

**热补丁相关：**
```bash
OSS_DbgShowAllUnifiedPatchstat   # 查看激活信息
OSS_DbgShowAllUnifiedPatchInfo   # 查看补丁详情
```

### 8. 安全注意事项

- **禁止**：在脚本中明文存储密码（开发环境除外）
- **必须**：操作前确认目标设备、槽位号、IP 地址
- **必须**：重要操作前进行数据备份
- **必须**：操作完成后及时清理临时文件
- **必须**：使用最小必要权限进行操作

## 最佳实践

1. 操作前先确认网络连通性（ping 测试）
2. 逐步操作，避免跳步
3. 重要操作记录日志便于追溯
4. 传输前检查目标磁盘空间
5. 使用绝对路径避免路径错误
6. 大文件传输时注意网络稳定性
